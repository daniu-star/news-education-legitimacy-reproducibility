# Final statistical model policy

This release uses the following model policy for the manuscript-facing analysis.

## Binary outcomes

Binary outcomes are estimated with marginal generalized estimating equations (GEE), using an exchangeable working correlation and `note_id` as the clustering unit. This applies to the binary outcomes in RQ1, RQ2, RQ3, and RQ4.

The model is a binomial GEE with a logit link. Coefficients are reported as odds ratios with 95% confidence intervals.

## Count outcomes

Positive like counts and reply counts are estimated with negative-binomial count models. These are not relabeled as GEE. The release records the count-model family and the treatment of within-note dependence separately.

## Historical cluster-robust GLM files

Some archived coefficient files were generated by an earlier binary GLM pipeline with cluster-robust standard errors. Those files are retained only as historical audit material and are not the manuscript-facing GEE results. They must not be cited as GEE estimates.

The formal GEE implementation is in `src/reproducible/final_analysis/run_complete_pipeline.py` and the standalone release runner is `src/reproducible/final_analysis/run_formal_gee_models.py`.
