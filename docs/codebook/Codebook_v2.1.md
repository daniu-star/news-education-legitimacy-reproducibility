# 新闻传播教育平台评价研究：内容分析编码手册 v2.0（可靠性检验后修订草案）

**版本状态**：第三轮定向复编码通过后正式冻结；用于后续全量v2重编码  
**修订依据**：400条分层样本中，既有全量LLM标签与盲态Agent独立复核之间的分歧  
**修订目标**：降低对象层级交叠、依据过度推断、复合立场压缩和能力属性错配，提高可复现性  
**编码单位**：单条当前评论；回复评论同时保留笔记标题与一级评论作为语境，但不得把上文立场复制给当前评论

---

## 一、第一轮可靠性诊断

第一轮400条盲态复核得到：

|变量|第一轮核心指标|结论|
|---|---:|---|
|评价对象|Micro-F1=0.704；平均二元α=0.569|未达到正式使用门槛|
|评价依据|Micro-F1=0.656；平均二元α=0.600|未达到正式使用门槛|
|全局立场|Macro-F1=0.618；名义α=0.539|未达到正式使用门槛|
|能力类型|Micro-F1=0.613；平均二元α=0.551|未达到正式使用门槛|
|能力属性|Micro-F1=0.267；平均二元α=0.370|严重不稳定|

主要问题不是个别错字，而是测量结构本身：

1. 一条评论可同时评价专业、职业、行业、课程和能力，原有“全局单一立场”无法准确对应多个对象；
2. “专业知识与理论”“公共价值”“身份情感”“无依据断言”常被当成内容主题而非真实论据；
3. 旧库将能力类型和能力属性存成两个独立数组，无法确认属性修饰哪项能力；
4. 编码者容易根据职业名称或公共价值表述推断能力，而不是只编码文本明确主张；
5. 资料推广、纯互动、非新闻传播主题与弱相关文本的处理标准不一致。

v2.0据此调整分析结构，而不是只修改若干类别名称。

## 二、总编码流程

每条文本按以下顺序处理：

1. 判断是否与新闻传播教育、学科、专业、能力、职业或行业评价相关；
2. 提取一个或多个**评价命题**，每个命题包含“对象—方向”；
3. 判断评论用什么证据支持这些命题；
4. 只在明确提到能力或具体行动时，建立“能力类型—能力属性”配对；
5. 回复文本再编码回复策略；
6. 判断是否建立课程、能力、职业和公共价值之间的明确连接；
7. 标记歧义来源与复核优先级。

不得先根据标题猜测立场，再反向寻找标签。

## 三、相关性门禁

新增变量：`relevance_status`。

|编码|定义|处理|
|---|---|---|
|核心相关|直接评价新闻传播教育、专业、学科、能力、职业或媒体行业|进入全部编码|
|语境相关|文本本身较短，但结合当前回复语境可识别其对新传议题的回应|进入编码，`context_dependent=1`|
|弱相关|评价其他文科、设备、工具、考试或个体，但与新闻传播教育联系不充分|对象通常记“未明确”，立场记“无法判断”|
|无关|案件、娱乐、体育、购物、快递等与研究问题无关|不进入核心模型；保留为采集噪声|

### 规则

- 标题涉及新闻学，不代表评论自动相关。
- 当前评论只有“是的”“笑死”“@某人”等内容时，除非上文使其立场唯一可识别，否则记为语境相关或无关，不推断复杂标签。
- 非新传专业的评价，不因其属于“文科”就自动转写为新闻传播评价。

## 四、评价命题：对象与方向成对编码

原有`evaluation_object[] + stance`改为：

```json
{
  "evaluations": [
    {"object": "专业", "stance": "认可"},
    {"object": "职业", "stance": "否定"}
  ]
}
```

这样可以保留“专业价值认可、就业结果否定”等复合结构。每条最多3个评价命题；超过3个时选择论证最明确的3个。

### 4.1 评价对象

#### 课程

编码条件：明确涉及课程设置、课堂内容、教师教学、作业、实践课、课程组织或教学评价。

- “剪辑课太多”→课程
- “老师不给PPT”→课程
- “学了四年没学到东西”若没有具体课程，优先编码知识或专业，不自动编码课程。

#### 知识

编码条件：明确评价理论、概念、教材、专业知识的深度、实用性、更新程度或解释力。

- “传播学理论都是名词堆砌”→知识
- “教材版本过时”→知识
- 仅推荐一本书而没有评价知识体系，不自动编码知识评价，可记中性信息行为。

#### 能力

编码条件：明确评价一种可执行的认知、生产、调查、判断或运营能力。

- “会写稿但不会核实”→能力
- “表达能力很有用”→能力
- 仅列举职业名称，不推断能力。

#### 专业

编码条件：对新闻学、新传、网媒、广告等专业整体价值、选择合理性、培养效果或专业身份进行概括判断。

- “新传是好专业”→专业
- “不要报新闻学”→专业
- “我新传毕业在做运营”只是在陈述去向时，优先职业，不自动加专业。

#### 职业

编码条件：讨论具体岗位、就业、薪酬、考公、升学作为职业路径、职业发展、劳动条件或岗位进入门槛。

- “记者工资低”→职业
- “考公岗位多”→职业
- “媒体已经没有公共性”若针对制度环境，优先行业。

#### 行业

编码条件：评价媒体行业、新闻业、报社、电视台、自媒体生态、平台制度或行业规范的总体状态。

- “新闻业被流量绑架”→行业
- “报社只出不进”→行业，也可同时职业
- 单个岗位待遇不等于行业。

#### 学科

编码条件：评价研究对象、学术知识生产、学科地位、理论原创性、论文和学术共同体。

- “新传没什么可研究的”→学科
- “某校新闻专业排名高”若只谈培养或报考，优先专业；若谈学科评估与研究实力，编码学科。

#### 未明确

只用于无法确定对象的相关短文本。对于完全无关文本，应由`relevance_status=无关`处理，不用“未明确”掩盖采集噪声。

### 4.2 评价方向

每个对象分别赋予一种方向：

|编码|操作性定义|
|---|---|
|否定|明确贬低、拒绝、劝退或判断价值不足|
|条件性否定|主导结论为负面，但指出特定学校、地区、能力、家庭条件或路径可例外|
|中性|提问、信息陈述、分类说明，没有价值倾向|
|条件性认可|主导结论为正面，但明确承认局限、成本或适用条件|
|认可|明确肯定价值、体验、能力或前景|
|无法判断|文本或语境不足以确认方向|

### 4.3 复合评价规则

- 不再强制将多个对象压缩为一个全局立场。
- “专业有趣，但就业工资低”→专业：认可；职业：否定。
- “课程很水，因此这个专业不值得报”→课程：否定；专业：否定。
- “记者辛苦，但社会仍需要记者”→职业：条件性否定或否定；行业／公共功能：认可，依据文本主张分别编码。
- 若正负判断指向同一对象且无法区分主次，才使用条件性认可／条件性否定；不要用“中性”掩盖明确的双向判断。

## 五、评价依据

评价依据只编码**被当前评论实际用来支撑评价命题的理由**。出现关键词不等于构成依据。

### 5.1 个人学习经历

必须有自身学习、课堂、课程、学校或备考体验。

- “我们学校水课很多”→个人学习经历
- “我觉得理论没意思”若由本人阅读体验支撑，也可编码。

### 5.2 实习就业经历

必须有本人实习、求职、工作、薪酬或职业经历。

- “我在报社五年，收入少了一半”→实习就业经历
- 对市场的一般判断，没有本人经历时不编码此项。

### 5.3 身边他人经历

必须明确提到同学、朋友、家人、同事、学长学姐或可识别他人个案。

### 5.4 招聘收入与市场结果

必须引用或概括岗位数量、招聘门槛、薪资、录取线、去向、地区机会、行业供需等外部结果。

- 个人工资既可编码实习就业经历，也可在其被用作市场判断时同时编码市场结果；若只是个人叙述，优先前者。

### 5.5 专业知识与理论

必须使用概念、理论、规范、历史事实、方法原则或专业分类进行论证。

- “新闻与宣传之争属于甘王之争”→专业知识与理论
- 仅表达一个看起来理性的意见，不自动编码。
- “事实要核实”若作为专业规范主张，可同时编码公共价值；不能只因语句正式就视为理论依据。

### 5.6 公共价值

必须诉诸真相、公共利益、社会责任、弱者保护、伦理、监督、知情权、社会记录等超出个人收益的标准。

- 对案件的一般道德谴责若与新闻教育无关，不进入核心评价依据。

### 5.7 AI与平台可替代性

AI、算法、自媒体或平台必须被用作解释专业、能力、职业或行业变化的因果依据。

- 只提到“用豆包”但没有评价能力时，可作为工具使用，不一定形成替代性依据。

### 5.8 身份情感

身份、归属、理想、骄傲、后悔、热血等必须构成评价理由，而不是仅仅出现情绪词。

- “我是新传人，所以仍相信新闻理想”→身份情感
- “笑死了”→反讽或梗／无法判断，不自动编码身份情感。

### 5.9 反讽或梗

反讽、夸张、网络梗必须承载对研究对象的评价。

- “泰坦尼克号上选座位”→反讽或梗
- 单纯表情、无对象的笑声不作为评价依据；立场通常无法判断。

### 5.10 无依据断言

这是**互斥性标签**：只有在存在明确评价命题，但评论未提供上述任何依据时使用。

- “新传就是垃圾”→无依据断言
- 已编码任一实质依据后，不再附加“无依据断言”。
- 提问、资料推广和无关文本不编码“无依据断言”。

### 5.11 多标签上限

最多3项。按“直接证据强度”排序，而不是按模型生成顺序。弱推断不得为了凑满标签而加入。

## 六、能力提及与属性配对

统一改为：

```json
{
  "ability_mentions": [
    {
      "ability_type": "事实核查与证据",
      "ability_property": "AI强化需求",
      "evidence_span": "AI越多越需要核实"
    }
  ]
}
```

### 6.1 纳入门槛

只有以下两种情况才编码能力：

1. 文本直接出现能力、技能、行动或认知过程；
2. 文本出现足以唯一对应能力类别的具体行为，如采访、查证、剪辑、运营、写稿。

不得根据岗位名称反推全部能力。例如“去财经媒体工作”不能自动编码采访、核查和议题发现。

### 6.2 能力类型

- 基础内容生产：写作、拍摄、剪辑、编辑、排版、海报、视频制作；
- 信息搜集整理：搜索、资料收集、整理、归纳、信息管理；
- 采访与信源关系：提问、采访、寻找或维护信源；
- 事实核查与证据：核实、溯源、调查、数据证据、验证真伪；
- 社会解释与议题发现：发现问题、框架化议题、解释社会过程、洞察；
- 伦理责任与公共判断：伦理决策、公共利益、伤害评估、责任判断；
- 平台运营与商业传播：账号运营、投流、品牌、营销、增长、产品传播；
- 其他：确有能力主张但无法归入以上类别，需记录原文并进入复核。

### 6.3 能力属性

能力属性必须有文本证据：

- 新闻专业独特：明确说“新闻的核心”“新闻人必须”“只有新闻训练”等；
- 大学教育通用：明确说任何专业、所有大学生、基本素质、谁都能学；
- 可跨职业迁移：明确说可用于其他行业、转行、多个岗位；
- 可由AI替代：明确说AI能完成或取代该能力；
- AI辅助强化：明确说AI作为工具增强但不完全替代；
- AI强化需求：明确说AI越发展越需要该能力；
- 未明确：能力被提到，但没有对其专业归属、迁移性或AI关系作判断。

### 6.4 禁止推断

- “事实核查很重要”不自动等于“新闻专业独特”；没有专属性判断时记“未明确”。
- “去做运营”不自动等于“可跨职业迁移”；只有文本比较专业与岗位迁移时才编码。
- “记者需要采访”不自动等于“新闻专业独特”；若文本只是岗位描述，属性记“未明确”。
- 每项属性必须对应一项具体能力，不允许独立属性数组。

## 七、回复策略

仅对回复层级且上文可用的文本编码。最多2项，第一项为主策略。

- 同层直接回应：回答上文问题或直接赞同／反驳其命题；
- 具体能力解释：用课程、知识或能力机制解释；
- 个人经验回应：以自己或具体他人经历回应；
- 市场结果回应：用薪资、岗位、门槛、地区机会等回应；
- 公共价值回应：诉诸公共利益、伦理或社会责任；
- 身份否定：以学历、学校、是否从业、是否懂行否定对方发言资格；
- 反讽与情绪：主要通过嘲讽、愤怒、安慰、玩梗回应；
- 话题转移：不处理原命题，转向无关内容、引流或@他人；
- 其他：无法归类，但有实质回应。

“同层直接回应”不应与所有具体策略机械共现。只有回复既直接回答、又明显使用另一种证据方式时才双标签。

## 八、价值转译

价值转译必须有明确的关系表达，不能因两个元素同时出现就自动建立连接。

|编码|最低证据|
|---|---|
|课程—能力连接|说明某课程、训练或教学如何形成具体能力|
|能力—职业连接|说明某能力如何进入岗位、薪资、就业或职业发展|
|能力—公共价值连接|说明某能力如何服务真相、公共利益、责任或社会参与|
|仅抽象价值表达|肯定或否定价值，但没有说明实现机制|
|无转译|没有跨层连接|

若一条评论同时建立两条连接，保留主连接，并在`secondary_translation_link`记录次连接。

## 九、歧义与复核字段

新增：

```json
{
  "ambiguity_flag": true,
  "ambiguity_type": ["对象层级交叠", "复合立场"],
  "confidence": 0.62,
  "evidence_span": "原文中支持标签的最短片段",
  "review_priority": "高"
}
```

歧义类型包括：

- 对象层级交叠；
- 复合立场；
- 反讽难判；
- 语境依赖；
- 相关性不足；
- 能力属性缺证据；
- 多标签边界；
- 文本残缺。

高优先级样本包括：条件性立场、多对象异向立场、反讽、作者回复、能力属性、弱相关文本。

## 十、第二轮可靠性门禁

在新的、未参与第一轮的分层样本上重新盲态编码。不得在第一轮400条上通过裁决后重新计算并宣称可靠性提高。

### 主指标

- 对象—方向评价命题：集合Micro-F1≥0.80，类别平均二元α≥0.80；
- 评价依据：Micro-F1≥0.80，类别平均二元α≥0.80；
- 能力类型：Micro-F1≥0.80；
- 能力属性：在有明确属性的能力提及子样本中Micro-F1≥0.80；
- 回复策略与价值转译：独立双编码样本α≥0.80；
- 0.67≤α<0.80只允许探索性使用并必须人工裁决；
- α<0.67不得承担论文核心推断。

### 结果报告

必须同时报告：

- 样本量与分层方式；
- 每类支持数；
- Precision、Recall、F1；
- Krippendorff’s α；
- 低频类别的置信区间或明确样本不足；
- 未通过类别及其处理方式；
- Agent复核与真正人类编码可靠性的区别。

---

## 十一、对全量标签的处理原则

1. 第一轮未通过可靠性门禁，因此冻结库中的旧标签只保留为`label_v1`；
2. 不直接覆盖旧标签；
3. 第二轮Codebook通过后，按变量决定重编码范围：
   - 评价命题、评价依据：全量重编码；
   - 能力提及：对候选能力文本全量配对重编码；
   - 回复策略与价值转译：对关系语料重编码；
4. 建立`label_version`、`coder_type`、`prompt_version`、`review_status`和`confidence`字段；
5. 论文只使用通过门禁的`label_v2_final`。

## 十二、示例

### 示例A：专业认可、职业否定

隐私化示例：“我并不后悔选择这个专业，但就业收入确实不高。”

```json
{
  "evaluations": [
    {"object":"专业","stance":"认可"},
```

## 十四、第二轮后新增裁决规则（v2.1）

### 14.1 相关性四分类的唯一判定顺序

第二轮分歧主要来自“语境相关”被过度扩张。v2.1固定以下顺序：

1. **核心相关**：当前评论自身包含关于课程、知识、能力、专业、职业、行业或学科的实质命题；对象名称可以省略，但必须能由标题或直接上文唯一恢复，且当前评论自身提供判断、问题、经验或理由。
2. **语境相关**：当前评论以“对、是的、有道理、但是、我做了多年、时薪也就这样”等指称性表达回应上文；脱离上文无法确定对象，但当前评论自身仍表达了明确的认可、否定、经验或结果。语境只能用于恢复对象，不能复制上文的立场、依据和能力标签。
3. **弱相关**：评论位于新闻传播相关笔记或线程中，但内容只是设备、宿舍、社团、联系人、资料、礼貌致谢、一般人生建议、泛化鼓励或无法与研究对象建立实质关系的旁支信息。弱相关不生成评价命题。
4. **无关**：文本及其可用语境均与新闻传播教育研究对象无关。

### 14.2 禁止从标题继承评价

- 标题为“新闻学就业好吗”，评论“谢谢学姐”不能继承“职业—认可”或“职业—否定”；仅记语境相关、未明确—无法判断，或在没有评价内容时记弱相关。
- 标题为“为什么当记者”，评论“好样的年轻人”可以在语境中识别为对职业选择的认可，但依据只能是“无依据断言”或身份情感，不能复制标题中的公共价值理由。
- 标题为“新闻专业劝退”，评论“换汉语言，去考公”自身提供替代路径，构成专业和职业否定，不属于简单语境继承。

### 14.3 短回复规则

- 纯“谢谢、好的、求、蹲、@某人、表情”不产生评价命题。
- “对、是啊、有道理”只有在直接上文对象唯一且当前表达明确同意时，才可建立“对象—认可／中性”命题；不得继承上文依据。
- 纯笑声、`doge`、玩梗只有在讽刺对象可唯一识别时才编码“反讽或梗”；否则只保留互动策略。

### 14.4 设备、生活与学习服务信息

- 电脑、相机、宿舍、社团和资料请求通常为弱相关。
- 当设备或软件被明确连接到课程任务或能力形成时，可编码课程、能力及“课程—能力连接”。
- 单纯说明“Mac能运行PS”可以记录基础内容生产能力候选，但不自动形成教育评价命题。

### 14.5 评价命题与回复策略分离

一条回复可以没有评价命题，但仍有回复策略。例如：

```json
{
  "relevance_status": "弱相关",
  "evaluations": [],
  "reply_strategy": ["个人经验回应"]
}
```

回复策略描述互动方式，评价命题描述研究对象判断，两者不得机械绑定。

### 14.6 第二轮结果的使用限制

第二轮240条样本显示，评价依据、能力配对、回复策略和价值转译的内部重复编码指标已达到预设门槛，但相关性分类及评价命题的类别平均α尚未达到0.80。第二轮样本只能用于继续修订和裁决，不得作为v2正式通过的独立验证证据。v2.1需在第三批全新定向样本上再次验证。

## 十五、第三轮冻结说明

第三批120条全新定向样本重点覆盖短回复、语境依赖、服务信息、弱相关文本、多对象评价和条件性立场。两次打乱顺序的同一Agent重复编码结果为：

- 相关性分类：Accuracy=0.958，Krippendorff’s α=0.934；
- 对象—方向评价命题：Micro-F1=0.969，类别平均二元α=0.888；
- 评价依据：Micro-F1=0.979，类别平均二元α=0.975；
- 回复策略：Micro-F1=0.994，类别平均二元α=0.997；
- 能力类型、显性能力属性与完整能力配对：Micro-F1均为1.000；
- 价值转译：Accuracy=1.000，Krippendorff’s α=1.000。

8条分歧已经逐条裁决，主要涉及纯情绪短回复、无直接上文的“对／我也是”、标题指称恢复和“身份情感—无依据断言”边界。

这些指标证明v2.1操作规则在同一Agent重复应用中的稳定性达到后续自动化重编码门槛，但不构成两名人类研究者之间的intercoder reliability。正式论文必须将其表述为“分层样本的双轮独立复编码／重复编码审计”；如期刊明确要求人工编码者间可靠性，仍需两名真实研究者在独立样本上复核。
