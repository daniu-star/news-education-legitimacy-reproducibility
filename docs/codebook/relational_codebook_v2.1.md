# 新闻传播教育平台评价研究：关系编码操作手册 v2.1

**版本状态**：正式冻结的关系语料编码规则  
**上位规则**：`01_reliability/Codebook_v2.1_正式冻结版.md`  
**分析单位**：一条可恢复的“直接上文—当前回复”关系  
**重要限制**：原数据库多数回复只能确认线程根评论；本阶段重建后，只有直接父级能够从字段或关系链中恢复时，才使用“直接回应”表述。

---

## 一、关系语料的三层上下文

每条关系同时保留：

1. `note_title`／`note_description`：笔记议题入口；
2. `thread_root_text`：线程一级评论；
3. `direct_source_text`：当前回复直接回应的上文；
4. `reply_text`：当前编码对象。

编码时优先使用`reply_text`，仅在其具有代词、省略或指称表达时使用`direct_source_text`恢复对象。`thread_root_text`只用于理解整条线程，不得把线程根的立场、依据或能力属性复制给当前回复。

---

## 二、关系类型

|关系类型|定义|论文表述|
|---|---|---|
|一级评论—直接回复|直接父级为一级评论|一级评论—回复关系|
|嵌套回复—直接父级可恢复|直接父级为另一条回复，并可沿链追溯至一级评论|嵌套回复关系|
|上文缺失不可恢复|直接父级或祖先节点不在数据库|不进入关系模型|
|原库标记孤立|治理阶段已标记孤立|不进入关系模型|

不得把全部回复写成“父评论—子评论完整树”。正式表述应为“可恢复的直接回复关系”与“线程级关系”。

---

## 三、编码字段

每条正式关系标签必须包含：

```json
{
  "relevance_status": "核心相关",
  "evaluations": [
    {"object": "职业", "stance": "否定"}
  ],
  "evidence_basis": ["实习就业经历"],
  "ability_mentions": [
    {
      "ability_type": "事实核查与证据",
      "ability_property": "AI强化需求",
      "evidence_span": "AI越多越要查来源"

  "review_status": "unreviewed"

```

## 四、回复策略

最多编码两项，第一项为主策略。

### 4.1 同层直接回应

直接回答、追问、赞同或反驳上文命题。纯“谢谢”“求”“蹲”“@某人”不属于实质直接回应。

### 4.2 具体能力解释

使用课程、训练、知识或具体能力机制说明问题。必须出现可识别能力或训练过程，不能因文本较长或语气理性自动编码。

### 4.3 个人经验回应

以本人或具体他人的学习、实习、求职、工作和职业经历回应。

### 4.4 市场结果回应

使用薪资、岗位数量、招聘门槛、录取线、地区机会、行业供需等可观察结果回应。

### 4.5 公共价值回应

诉诸真相、公共利益、社会责任、新闻伦理、知情权、舆论监督或公信力。

### 4.6 身份否定

以学历、学校、是否学过新闻、是否从业或是否懂行为由，否定对方的发言资格。单纯说明自己的身份不等于身份否定。

### 4.7 反讽与情绪

主要通过嘲讽、愤怒、安慰、玩梗或强烈情绪回应。表情符号只在确实承载策略时编码，不能见到表情即自动归类。

### 4.8 话题转移

不处理原命题，转向资料、广告、设备、生活信息、@他人、纯致谢或其他旁支内容。

### 4.9 其他

存在实质回应但无法归入以上类别。必须填写理由并进入中高优先级复核。

## 五、价值转译

价值转译要求当前回复明确建立跨层关系，不能只因两个概念同时出现就判定连接。

|编码|最低证据|
|---|---|
|课程—能力连接|说明课程、教学或训练如何形成具体能力|
|能力—职业连接|说明具体能力如何影响岗位进入、薪资、就业或职业发展|
|能力—公共价值连接|说明能力如何服务真相、公共利益、责任或社会参与|
|仅抽象价值表达|表达专业理想、公共价值或意义，但没有说明实现机制|
|无转译|没有形成跨层连接|

同一回复同时建立两条连接时，将论证最明确者记为主连接，另一条进入`secondary_translation_link`。

## 六、相关性与短回复

1. 纯致谢、求取、蹲、@、表情通常记为弱相关，不生成评价命题；
2. “对”“是的”“没错”等只有在上文对象唯一时，才可恢复对象，但不得继承上文依据；
3. 设备、宿舍、社团、资料等通常为弱相关；只有明确连接课程或能力时才进入教育评价；
4. 与研究完全无关的体育、娱乐、购物等线程记为无关；
5. 回复策略与评价命题分开：弱相关回复仍可能具有“话题转移”或“个人经验回应”策略。

---

## 七、预标注与最终标签的边界

`reply_strategy_translation_seed_labels.csv.gz`是高精度规则预标注，只用于排序复核工作量：

- `seed_review_priority=低`：规则较明确，仍需抽检；
- `seed_review_priority=中`：需语义复核；
- `seed_review_priority=高`：未命中规则或存在复杂关系，必须逐条复核。

预标注不得直接进入RQ2模型，不得用于计算正式比例。只有`review_status=final`且`label_version=v2.1`的标签可以进入论文推断。

---

## 八、质量控制

1. 每批200条；
2. 每完成5批，随机复核20条；
3. 作者回复、嵌套回复、条件性立场、能力属性、价值转译和反讽均为高优先级；
4. 发现系统性错误时，冻结当前批次并回溯同类规则；
5. 正式标签必须通过JSON合法值检查、空字段检查和主键唯一性检查；
6. 每一条修改保留`old_label`、`new_label`、`reason`和`reviewer`。
