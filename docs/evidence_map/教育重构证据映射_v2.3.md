# 教育重构证据映射 v2.3

## 从下游结算转向多维结果评价

就业率不能独占教育价值的结算权。评价体系应同时纳入职业迁移、事实质量、社会解释、伦理判断与公共贡献。

## 从公共价值宣示转向公共能力操作化

真实性、社会责任和公共服务应转化为核查、信源保护、算法公平、错误修正与人工智能责任等可教学和可评价的能力。

## 从产出展示转向判断展示

课程成果需要记录选题形成、信源判断、核查过程、证据冲突、伦理决策和人工智能使用，使隐藏在生产过程中的专业判断获得公共可见性。

## 从模块化改革转向组合型合法性建构

课程、能力、职业、技术适应和公共价值应形成相互支撑的证据链。院校应明确差异化培养承诺，并持续验证课程增值与社会贡献。
