# 研究发现证据映射 v2.3

## 发现一 教育价值的下游结算

核心证据为市场结果与否定评价的稳定关联，以及评论区就业框架相对笔记端的平均增加。该发现解释评价尺度如何向职业下游迁移。

## 发现二 公共性的双向争夺

核心证据为公共价值同时连接认可、点赞可见性与否定评价。该发现解释公共价值如何从学院的自我证明转化为用户审查教育实践的尺度。

## 发现三 专业性的可见性悖论

1959个显性能力提及中，前台技能1467个，高阶能力492个。前台技能承载52个明确属性判断，高阶能力仅5个。全部9个明确的人工智能替代判断都位于前台技能。该发现说明人工智能首先击中由可见技能代表的专业形象，高阶能力的问题主要是教育归属不可见。

## 发现四 理由分裂与判决收敛

负向评价能够吸收就业、行业、技术、课程和公共价值等异质理由，并汇聚为同向否定。强正向关系极少，支持性论证承担更高证明责任。该发现解释专业合法性危机为何具有多入口和非对称性。
