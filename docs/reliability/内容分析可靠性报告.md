# 新闻传播教育平台评价研究：阶段1内容分析可靠性最终报告

**版本**：v1.0  
**完成日期**：2026-08-04  
**数据入口**：`00_freeze/analysis_v2_frozen.db`  
**正式编码手册**：`01_reliability/Codebook_v2.1_正式冻结版.md`

## 一、目的与边界

本阶段检验旧版标签的测量稳定性，修订对象—立场、评价依据、能力配对、回复策略与价值转译规则，并为全量v2重编码建立可执行的操作手册。全部编码由当前Agent完成。第一轮为既有LLM标签与盲态Agent复核的比较；第二、三轮为同一Agent在打乱顺序、物理隔离文件条件下的重复编码审计。

因此，本报告不得被改写为“两名人类编码员取得高可靠性”。它提供的是旧标签审计证据、Codebook修订证据和同一Agent操作规则的重复稳定性证据。

## 二、三轮推进

### 第一轮：400条诊断样本

- 评价对象Micro-F1=0.704，平均二元α=0.569；
- 评价依据Micro-F1=0.656，平均二元α=0.600；
- 全局立场Macro-F1=0.618，名义α=0.539；
- 能力类型Micro-F1=0.613，平均二元α=0.551；
- 能力属性Micro-F1=0.267，平均二元α=0.370。

结论：旧版`评价对象数组+单一全局立场`以及`能力类型数组+能力属性数组`不能支撑强推断。第一轮只用于诊断，旧标签保留为`label_v1`。

### 第二轮：240条全新分层样本

重点覆盖来源、层级、作者回复、AI、就业、公共价值、反讽、多标签、能力提及和弱相关文本。

- 相关性分类：Accuracy=0.825，α=0.751；
- 评价命题：Micro-F1=0.874，平均二元α=0.763；
- 评价依据：Micro-F1=0.897，平均二元α=0.873；
- 回复策略：Micro-F1=0.842，平均二元α=0.875；
- 能力配对：Micro-F1=0.930，平均二元α=0.960；
- 价值转译：Accuracy=0.988，α=0.952。

结论：依据、能力、回复和转译规则基本稳定，但“弱相关／语境相关”边界导致评价命题平均α未达0.80。44条分歧逐条裁决后形成v2.1。

## 三、正式决定

1. `Codebook_v2.1_正式冻结版.md`成为下一阶段唯一编码规则。
2. 冻结库中的旧标签继续保留为`label_v1`，不得直接覆盖。
3. 后续建立`label_v2_raw`、`label_v2_reviewed`和`label_v2_final`三个版本层。
4. 全量评价命题与评价依据需按v2.1重新编码；不能把旧数组机械转换为对象—方向配对。
5. 候选能力评论按配对式`ability_mentions`重编码。
6. 线程回应关系按回复策略与价值转译规则重编码。
7. 每轮全量编码后抽取不少于5%的高歧义与低置信样本复核。

## 四、仍然存在的限制

- 第三轮样本量为120，部分条件性立场、学科评价和显性AI属性支持数较少；总体通过不等于每个低频类别都已获得精确估计。
- 能力属性第三轮仅覆盖“新闻专业独特、大学教育通用、可跨职业迁移”三类显性属性；“AI替代、AI辅助、AI强化需求”需在全量重编码前追加定向审计。
- 回复策略与价值转译的正式质量检验仍需在真实关系语料样本中单独进行，单评论样本中的结果不能完全代替阶段2关系编码可靠性。
- 当前结果属于同一Agent重复编码稳定性，而非人类编码者间可靠性。

## 五、论文可用表述

可写：

> 研究首先对既有自动标签进行分层盲态审计。第一轮400条样本暴露出对象与全局立场错配、能力类型与属性无法对应等问题。研究据此修订编码手册，将评价重构为对象—方向命题，并将能力改为类型—属性配对。随后在两批未参与修订的全新样本上进行重复编码审计，第三批定向样本中，相关性分类Krippendorff’s α为0.934，对象—方向命题Micro-F1为0.969，类别平均二元α为0.888。

必须同时说明：

> 上述指标反映自动化编码流程的重复稳定性，不替代两名人类编码者之间的可靠性检验。

禁止写：

- “两名人工编码员独立编码并达到α>0.80”；
- “旧版21,779条标签均已验证可靠”；
- “所有能力属性类别均已充分验证”。
