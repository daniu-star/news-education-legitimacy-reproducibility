# terminal v2.3版本说明

本版本完整继承terminal v2.2中的数据治理、编码、模型、稳健性检验、争议网络和终版数据库，不修改既有计算结果。

本次升级集中于论文表达和第三项研究发现深化。第三项发现由“能力边界低显化”推进为“专业性的可见性悖论”。新增内容包括摘要定稿、第三项发现深化稿、四项发现最终结构、研究发现与教育重构证据映射、更新结果卡以及能力可见性悖论复算脚本和统计结果。

本版本不改变以下方法边界。Agent复核不得写成两名真实人类编码者间可靠性。显性能力属性数量较少，不得推断平台总体人工智能替代率。browser来源具有高可见评论偏差。历史v1标签只可在稳健性边界内使用。
