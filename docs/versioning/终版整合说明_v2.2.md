## 三、编码证据等级

- 逐条Agent裁决：可用于核心关系分析，但不能冒充人类编码；
- 高置信校准混合：可用于扩展模型和稳健性；
- 低置信混合：只能用于敏感性检验；
- 历史v1全量标签：用于全量对象—依据—立场模型，必须同步报告v2审计边界；
- 严格的两名真实人类编码者间可靠性仍需研究团队补充。

## 四、第四研究发现的定位

第四项发现修订为：

> **同题异判：新闻传播教育合法性的多尺度争议与证据断裂。**

它不支持“新闻传播机构普遍不会传播”。它说明参与者通常围绕同一教育对象争论，却使用市场、经验、身份、知识、公共价值和AI等不同尺度，课程—能力—职业—公共价值之间的跨层转译较少。教育落点是建设多尺度价值基础设施，而不是增加一般性的宣传。

## 五、复现环境

核心脚本使用Python、pandas、numpy、statsmodels、scikit-learn、networkx与SQLite。运行前请按脚本实际import安装依赖。

争议网络复算示例：

```bash
python 06_争议网络/recompute_controversy_network_v2_2.py \
  --db 02_数据库与数据冻结/analysis_terminal_v2.2.db \
  --relation-frame 03_关系编码/relation_full_terminal_frame.csv.gz \
  --out controversy_recomputed
```
