# Data Availability

## Public

The repository contains codebooks, prompts, computational scripts, model specifications, reliability summaries, aggregate coefficient tables, robustness checks, transition matrices and aggregate network outputs.

## Not public

Raw platform data and row-level derived records are not distributed. This includes user-generated text, titles, URLs, platform identifiers, user identifiers/hashes, IP-location fields, exact timestamps, raw/analysis databases, reply-pair records, comment-level labels, embeddings and audit samples containing record identifiers.

This restriction is intentional to reduce privacy, re-identification and platform-compliance risks. Researchers seeking to reproduce the workflow should use independently collected data that conform to `docs/data_schema_public.md`.
