# Historical cluster-robust GLM outputs

The coefficient files under `rq1/` and `rq4/` whose names contain
`cluster_glm` were generated by an earlier binary GLM pipeline with cluster-
robust standard errors. They are retained for audit history only.

They are not the manuscript-facing GEE estimates and must not be described as
GEE in the paper. To generate the formal binary outputs, run:

```bash
python src/reproducible/final_analysis/run_formal_gee_models.py
```

The resulting files are written to a separate `formal_gee_results/` directory
by default, which prevents accidental overwriting of the historical archive.
